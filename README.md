## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/debanjan100/Leetcode.git
cd Leetcode
```

Browse a problem folder and open the solution file:

```bash
ls
cd 20-valid-parentheses
```

Then run the solution with Python:

```bash
python valid-parentheses.py
```
